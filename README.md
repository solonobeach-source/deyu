# Дею

Задачи и режим фокуса для macOS. Меньше отвлечений — больше действия.

«Дею» — старая форма слова «делаю». Пишешь список дел, жмёшь «Начать» — список прячется, на экране остаётся маленькая плашка с одной задачей и таймером. Раз в несколько минут она мягко напоминает о себе.

## Установка

1. Открой Deyu.dmg и перетащи «Дею» в папку «Программы».
2. При первом запуске macOS скажет: «Apple не удалось подтвердить…». Это нормально: приложение не подписано платным сертификатом Apple. Нажми **Готово**.
3. Открой **Системные настройки → Конфиденциальность и безопасность**, пролистай вниз и нажми **Всё равно открыть**, подтверди паролем.

Дальше «Дею» открывается как обычно. На macOS 14 и раньше проще: правый клик по «Дею» → Открыть → Открыть.

## Что внутри

- Список задач: добавить, переименовать кликом, отметить, удалить.
- Режим фокуса: плашка поверх всех окон, её можно таскать; при наведении — «Готово» и «Список».
- Напоминания: 10 анимаций, интервал от 1 до 15 минут. После 30 минут без остановки — подсказка сделать перерыв.
- Тёмная тема, похвала за сделанные дела.

## Данные и приватность

Задачи хранятся только на твоём Mac. Приложение отправляет анонимную статистику использования — сколько задач создано и закрыто, сколько длится фокус, какие настройки выбраны — без названий задач и без личных данных. Выключить: меню «Дею» → «Отправлять анонимную статистику».
